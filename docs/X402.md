# x402 — Agent Wallet / Pay-per-Call (no registration)

Universal payment layer for AI agents: pay with USDC via [x402 protocol](https://x402.org) without creating an account.

## Three access modes

| Mode | Auth | Best for |
|------|------|----------|
| **Free API key** | `Authorization: Bearer sk_live_...` | Humans, dev, free tier (100 units/day) |
| **x402 wallet** | `PAYMENT-SIGNATURE` header | Autonomous agents, MCP, no signup |
| **Subscription** | WayForPay / Stripe (Phase B) | Monthly plans (coming soon) |

Tool routes accept **either** API key **or** x402 payment.

## Friction — choose the right path

| Path | Agent friction | What the agent needs | Best for |
|------|----------------|----------------------|----------|
| **`POST /v1/register {}`** | **Lowest** | Nothing — instant API key | Default for autonomous agents |
| **`POST /v1/register/agent`** | **Low** | agent_id + TOS version | Named production agents |
| **x402 testnet** | Medium | Wallet + faucet USDC (free) | Dev, wallet-only agents, no signup |
| **x402 mainnet** | **High** | Wallet + **real USDC** + **ETH gas** on Base | Agents with pre-funded treasury only |

**Important:** CDP API keys are **operator/server** setup — not something the calling agent configures. Mainnet still hits the agent with USDC liquidity and gas costs.

**Default recommendation for agents:** `GET /v1/onboarding` → `POST /v1/register` with `{}`. Use `/v1/register/agent` only when you need a named agent id. Use x402 only when the agent must stay wallet-only or already holds Base USDC.

Programmatic guidance: `GET /v1/x402/info` → `agent_guidance` and `network.agent_friction`.

## Flow

```
1. POST /v1/extract          (no API key)
   → 402 Payment Required
   → Header: PAYMENT-REQUIRED (base64 JSON: amount, network, payTo)

2. Agent signs USDC transfer (EIP-3009) from wallet

3. POST /v1/extract + PAYMENT-SIGNATURE
   → verify + settle via facilitator
   → 200 OK + result + PAYMENT-RESPONSE (tx receipt)
```

| Endpoint | Description |
|----------|-------------|
| `GET /v1/x402/info` | Network, setup, MCP env hints |

## Step 3 — Testnet (Base Sepolia)

**Server `.env`:**

```env
X402_ENABLED=true
X402_ENV=testnet
X402_PAY_TO=0xYourReceiveWallet
```

- Network: `eip155:84532`
- Facilitator: `https://x402.org/facilitator` (no signup)
- Install: `pip install -r requirements-x402.txt`

**Get test USDC:**

1. [Circle Faucet](https://faucet.circle.com/) — select **Base Sepolia**
2. [CDP Faucet](https://portal.cdp.coinbase.com/products/faucet)
3. [Alchemy Base Sepolia](https://www.alchemy.com/faucets/base-sepolia) — small ETH for gas

**Test client:**

```powershell
$env:X402_PRIVATE_KEY = "0x..."
$env:X402_NETWORK = "eip155:84532"
python scripts/x402_test_client.py
```

## Step 4 — Mainnet (Base)

> **High agent friction.** Only use when the agent already has USDC + ETH on Base. For new agents, prefer `POST /v1/register/agent` (free API key) or testnet x402.

**Operator (API server) `.env`:**

```env
X402_ENABLED=true
X402_ENV=mainnet
X402_PAY_TO=0xYourBaseWallet
CDP_API_KEY_ID=your-key-id
CDP_API_KEY_SECRET=your-key-secret
```

- Network: `eip155:8453`
- Facilitator: `https://api.cdp.coinbase.com/platform/v2/x402` (auto)
- CDP keys: [portal.cdp.coinbase.com](https://portal.cdp.coinbase.com/)
- Requires `cdp-sdk` (included in `requirements-x402.txt`)

**Agent wallet requirements:**

- Real USDC on Base mainnet (~$0.001 per call minimum)
- ETH on Base for gas (keep a small balance)
- No faucets — must bridge, buy, or receive from treasury

**Client:**

```env
X402_PRIVATE_KEY=0x...
X402_NETWORK=eip155:8453
```

Buyer wallets need real USDC on Base mainnet.

## When *not* to use x402 mainnet

- Agent has no crypto wallet yet → `POST /v1/register/agent`
- Agent cannot acquire USDC/ETH autonomously → free API key or subscription (Phase B)
- Integration/dev testing → testnet x402 + Circle faucet
- Operator has not set CDP keys yet → mainnet x402 will not settle

## MCP (Cursor / Claude)

Either auth method in `mcp.json`:

```json
{
  "mcpServers": {
    "agenttools": {
      "command": "D:\\Web4\\.venv\\Scripts\\python.exe",
      "args": ["D:\\Web4\\mcp\\server.py"],
      "env": {
        "AGENTTOOLS_API_URL": "https://api.toolsforagents.tools",
        "X402_PRIVATE_KEY": "0x...",
        "X402_NETWORK": "eip155:84532"
      }
    }
  }
}
```

Or with API key:

```json
"AGENTTOOLS_API_KEY": "sk_live_..."
```

MCP tool `x402_info` returns server payment config + current MCP auth mode.

When `X402_PRIVATE_KEY` is set, MCP auto-handles 402 responses via `wrapHttpxWithPayment`.

## HTTP 402 types

| Response | Meaning |
|----------|---------|
| `error: payment_required`, header `PAYMENT-REQUIRED` | x402 — sign and retry |
| `error: quota_exceeded` | Free tier limit — upgrade or pay via x402 (if enabled) |
| `error: quota_exceeded_or_payment_required` | Quota hit + x402 alternative in same 402 |

## Pricing

Default: **$0.001 per unit** (minimum $0.001 per call).

Examples: `extract` = 1 unit = $0.001, `pdf` = 2 units = $0.002.

Live table: `GET /v1/x402/pricing` or [pricing.html](../deploy/website/pricing.html#x402).
